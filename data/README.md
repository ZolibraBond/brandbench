# BrandBench Data Directory Structure

This directory contains all data generated by BrandBench, organized by type and timestamp.

## Directory Structure

```
data/
├── responses/           # Raw API responses from prompt execution
├── sentiment/           # Sentiment analysis results
├── analysis/           # Combined analysis and metrics
└── reports/            # Generated reports and summaries
```

## File Naming Convention

All files follow the format: `YYYYMMDD_HHMMSS_<type>.json`

Example: `20250722_143021_responses.json`

## File Types

### responses/
Contains raw responses from OpenAI API executions:
- Prompt text
- Response content
- Metadata (timestamps, model, usage stats)
- Web search information (if enabled)

### sentiment/
Contains sentiment analysis results:
- Individual sentiment scores per response
- Aggregated metrics by brand
- Reference to source response file

### analysis/
Contains combined analysis:
- Brand mention detection results
- Recall metrics
- Performance metrics over time

### reports/
Contains generated reports:
- Summary statistics
- Visualizations data
- Exported results for external analysis

## Data Flow

1. **Prompt Execution** → `responses/YYYYMMDD_HHMMSS_responses.json`
2. **Sentiment Analysis** → `sentiment/YYYYMMDD_HHMMSS_sentiment.json`
3. **Combined Analysis** → `analysis/YYYYMMDD_HHMMSS_analysis.json`
4. **Report Generation** → `reports/YYYYMMDD_HHMMSS_report.json`
